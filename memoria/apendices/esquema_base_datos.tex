\chapter{Esquema de la base de datos}\label{cap:esquemaBD}

Este apéndice recoge, a nivel de detalle de campo, el esquema completo de las tablas de PostgreSQL~\cite{postgresql} introducidas en el apartado \nameref{sec:disenoBD} (Sección~\ref{cap:1_iteracion}), incluyendo los tipos de dato de cada campo y las claves primarias y foráneas. Los tipos de dato mostrados corresponden a tipos nativos de PostgreSQL (\texttt{BIGINT}, \texttt{VARCHAR}, \texttt{TEXT}, \texttt{BOOLEAN}, \texttt{TIMESTAMP}, \texttt{DOUBLE PRECISION}) o a tipos enumerados propios (\texttt{ENUM}) definidos para este esquema.
